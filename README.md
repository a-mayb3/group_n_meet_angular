# group_n_meet_angular

- [group_n_meet_angular (this repository)](https://git.vollex.cc/a-mayb3/group_n_meet_angular)

Recommended to use with [group_n_meet_deployment](https://git.vollex.cc/a-mayb3/group_n_meet_deployment).
